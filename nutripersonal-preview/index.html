Política de privacidade

Dados do planejador

Os dados informados no planejador são processados no seu navegador e, nesta versão, não são enviados ao servidor nem armazenados em banco de dados pela NutriPersonal.

Dados de contato

Se você preencher o formulário de interesse, nome e e-mail poderão ser armazenados pela infraestrutura de formulários da Netlify para contato sobre o produto.

Código de acesso

O código digitado para liberar a versão completa é enviado à função de validação da Netlify e não é armazenado pelo app.

Antes do lançamento

Devem ser inseridos identificação jurídica do fornecedor, canal de privacidade e procedimento para solicitações do titular.

Versão preliminar para MVP. Revisão jurídica profissional recomendada antes de escalar vendas.

Termos de uso

Natureza do serviço

A NutriPersonal é uma ferramenta educacional de organização alimentar para adultos saudáveis. Não realiza diagnóstico, consulta ou prescrição dietética clínica.

Limitações

As estimativas são aproximações matemáticas. Situações clínicas, gestação, lactação e necessidades terapêuticas exigem acompanhamento profissional.

Fornecedor

Antes da venda definitiva, preencher razão social/nome empresarial, CPF/CNPJ, endereço comercial e canal de suporte.

Versão preliminar para MVP. Revisão jurídica profissional recomendada antes de escalar vendas.
